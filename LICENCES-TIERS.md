# Composants tiers

Le code de l’application est fourni avec ses sources. Les composants tiers conservent leurs licences et avis d’origine.

- Python : licence PSF — https://docs.python.org/3/license.html
- PySide6 et Shiboken6 : LGPLv3/GPLv3 ou licence commerciale Qt — https://www.qt.io/licensing/open-source-lgpl-obligations
- Qt 6 : licences LGPLv3/GPLv3 et licences de ses composants tiers — https://doc.qt.io/qt-6/licenses-used-in-qt.html
- Pillow : licence HPND — https://github.com/python-pillow/Pillow/blob/main/LICENSE
- tzdata : Apache-2.0 pour le paquet Python, données IANA sous leurs conditions — https://github.com/python/tzdata
- PyInstaller : GPL avec exception permettant la distribution des applications produites — https://pyinstaller.org/en/stable/license.html

Les avis disponibles dans les paquets utilisés sont copiés dans le dossier `Licences` de la livraison Windows. Les bibliothèques Qt sont chargées dynamiquement. Le code source de l’application et les instructions de reconstruction sont livrés afin de permettre l’usage de versions modifiées de ces bibliothèques. Les sources de Qt et PySide correspondant aux versions utilisées sont accessibles via https://download.qt.io/official_releases/ et https://code.qt.io/pyside/pyside-setup.git/ .
